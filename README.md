# NEVERWIN

> «Экстернал чит», который гарантирует, что ты **никогда** не выиграешь.

Шуточный / мемный проект. Это **не** настоящий чит: он не читает и не пишет
в память чужих процессов, не лезет в игру и не обходит античит (и не сможет —
все «фичи» специально ломают *тебе* игру). Меню и переключатели настоящие,
эффект — самоирония.

## Запуск

Требуется Python 3 + Tkinter (обычно есть из коробки, на Debian/Ubuntu:
`sudo apt install python3-tk`).

```bash
python3 neverwin.py
```

## Вкладки и функции

### COMBAT
- **ANTI-AIMBOT** — прицел сам отводится от врагов (гарантия промаха).
- **ANTI-AIMLESS** — увидел врага → камера резко выкручивается куда-то далеко.
- **GAMESENSE** — включить нельзя. Пока выключен: на перезарядке оружие
  выпадает из рук с шансом 20%.

### RENDER
- **ESP** — рисует «фейк»-позиции врагов там, где их на самом деле нет.
- **VISUAL RECOIL** — отдача +400%, целиться невозможно.

### MOVEMENT
- **ANTI-BHOP** — прыжок заблокирован, пока включён.

## Структура
- `neverwin.py` — вся программа: меню, вкладки, переключатели, лог-консоль.
